# ringuri

Ring encode/decode helpers for uri payloads in pipelines.

**Site:** https://theworker02.github.io/ringuri/

## Install / run

```bash
git clone https://github.com/theworker02/ringuri.git
cd ringuri
node src/cli.js
node --test
```
